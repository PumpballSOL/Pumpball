# BRAND

Green, black, white. Pump.fun-inspired, lottery-machine energy. Polished, technical, slightly degen.

## Palette

| Name | Hex | Use |
| :--- | :--- | :--- |
| Pump Green | `#00FF88` | Primary accent, highlights, active states |
| Deep Green | `#00B85C` | Glitch layers, gradients |
| Black | `#050505` | Backgrounds |
| Panel | `#070B08` | Terminal and card backgrounds |
| Line | `#1C3A2A` | Borders, inactive strokes |
| Gray | `#7A8A80` | Labels, secondary text |
| White | `#FFFFFF` | Headlines, values |
| Pending Yellow | `#FFD84D` | `PENDING` states only |

## Type

- **Display:** heavy sans (Arial Black / Impact fallback stack), tight and wide
- **Everything else:** monospace (`ui-monospace, SFMono-Regular, Menlo, Consolas`)

## Voice

Short. Flat. Confident. Slightly degen.

| Do | Don't |
| :--- | :--- |
| `Pump. Hold. Draw. Win.` | Promise returns or guaranteed prizes |
| `TBA` for anything unknown | Invent addresses, stats or dates |
| `> waiting for the next draw_` | Over-explain |
| One ball. One wallet. One winner. | Use the word "guaranteed" |

## Logo

The mark is a split ball, white over green, with a pill in the center ring. Use [`assets/pumpball.png`](../assets/pumpball.png). Keep clear space of at least half the ring diameter, and do not recolor it.
