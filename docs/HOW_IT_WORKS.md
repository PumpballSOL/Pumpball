# HOW IT WORKS

> Pump. Hold. Draw. Win.

## The 10-second version

```text
PUMP.FUN
   │
   ▼
TRADING FEES
   │
   ▼
PUMPBALL
   │
   ▼
PRIZE POOL
   │
   ▼
DRAW
   │
   ▼
WINNER
```

Pump.fun token activity generates fees. Those fees accumulate into a prize pool. At predetermined drawings, eligible PUMPBALL holders have a chance to win the accumulated prize.

**Buy PUMPBALL → Hold PUMPBALL → Enter the draw.**

## Stage by stage

| # | Stage | What happens |
| -: | :--- | :--- |
| 01 | **PUMP.FUN** | PUMPBALL is a token on Pump.fun. There is no custom launchpad and no separate platform. |
| 02 | **TRADING FEES** | Trading activity on the token generates fees. |
| 03 | **PUMPBALL** | The fees are routed toward the PUMPBALL prize pool. |
| 04 | **PRIZE POOL** | The pool accumulates between draws. Its size depends entirely on trading activity. |
| 05 | **DRAW** | At a predetermined drawing, eligible holders are entered. |
| 06 | **WINNER** | One wallet wins the accumulated prize. The payout is published on-chain. |

## What PUMPBALL is not

- Not a launchpad. It lives on Pump.fun.
- Not a dashboard or an app. The README is the product for now.
- Not a promise of returns or prizes. See the [disclaimer](../README.md#disclaimer).
